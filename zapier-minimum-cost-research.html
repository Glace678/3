  • 添加 OPENAI_API_KEY（用 GPT 系列模型时）
  • 和/或添加 ANTHROPIC_API_KEY（用 Claude 系列模型时）
  • Key 仅存储在 GitHub Secrets，脚本不记录、不输出

2提交新文件到仓库

git add .github/workflows/provider-review.yml \
        .github/zapier-review/provider-autonomous.mjs \
        .github/zapier-review/provider-api.mjs
git commit -m "feat: provider API direct review (0 Zapier tasks)"
git push origin main

3试运行（plan_only，不调用模型）

  • 打开 https://github.com/Glace678/3/actions/workflows/provider-review.yml
  • 点击 "Run workflow"，plan_only 选 true
  • 验证分批准备正常（~72 批，不消耗任何费用）

4正式运行

  • 创建一个 Issue（标题以 [review] 开头 = 只审核模式）
  • 手动 Run workflow，填入 Issue 编号，plan_only 选 false
  • model_id 可选：openai/gpt-5.6-luna（最便宜）/ openai/gpt-5.6-sol / anthropic/claude-fable-5
  • 全仓审核约 2-5 小时（取决于模型速度），完成后自动创建草稿 PR

⚠️ 风险与注意事项

  • SDK Beta 免费不永久：当前架构依赖 SDK Beta 免费。官方明确"Beta 结束前会通知"。一旦结束，每个 SDK action 可能计 1 task，72 批 = 72 tasks/issue。直连 provider API 方案不受此影响。
  • Provider API Key 安全：Key 存储在 GitHub Secrets，脚本仅从环境变量读取，不记录不输出。请勿将 Key 写入代码或日志。
  • Token 预算保护：provider-autonomous.mjs 内置 token 预算（默认 1 亿），超出自动停止，防止 runaway 费用。
  • GPT-5.6 Sol 促销价：$4/$20 为促销价，至少维持至 2026-11-21，之后可能回调至 $5/$30。长期预算建议预留上浮空间。
  • 不自动合并 PR：所有方案均创建草稿 PR（draft），需人工审查后合并。不执行模型生成的脚本。
  • 覆盖验证：每批结果通过 SHA256 清单 + 覆盖范围校验，确保不遗漏文件。
